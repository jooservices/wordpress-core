# D4 PHP >= 8.1 and WordPress >= 6.6

- Status: Accepted
- Date: 2026-10-14
- Jira: JOOWT-40 (P7.1), JOOWT-4 (C1)

## Context
Modern language features and stable block and script-module APIs.

## Decision
PHP 8.1+ (Docker runtime 8.3), WordPress 6.6+ tested on the minimum and the latest release.

## Alternatives considered
- PHP 7.4 / WP 5.x: blocks modern code.

## Consequences
- Hosts below the minimum are unsupported.
