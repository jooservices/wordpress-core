# Terminal

A read-only Ubuntu-like shell docked at the side of the page. Nothing typed is sent anywhere.

## Data
`Terminal\FsBuilder` builds the tree from published, non-protected content; `GET /joo/v1/terminal/fs?lang=` serves it (cached with tags, HTTP-cacheable). Categories are directories (slug chain of the hierarchy), posts are `<slug>.md` in their primary category (links in the other categories; same slug in one directory becomes `<slug>-<id>.md`), `/tags/<slug>/` hold links, `/pages`, `/authors`, `/README.md` and a hidden `/.config`. Titles and excerpts are plain text; `terminal.max_posts` (default 500, newest first) and a 400 KB cap (`truncated: true`) bound the size.

## Engine (`resources/js/terminal/`)
`engine.js` is the pure shell core: `fs.js` (path resolution with `.`, `..`, `~`, link loop guard), `shell.js` (tokenizer, history, completion, did-you-mean, unsupported operators) and the command registration API. It has no DOM, network or `location` access (enforced by ESLint and a test). Its standalone production bundle is 4,599 B gzip against the 5,120 B (5 KiB) engine budget. Built-in command handlers and the browser UI are excluded from this engine measurement. Results are structured data: `{blocks, exitCode, navigate?, effects?}`.

Built-in commands: `help ls ll cd pwd cat head tree find grep open xdg-open go curl theme lang whoami hostname id uname date echo history clear exit logout man which neofetch ping sudo` and the write commands (`rm rmdir mv cp touch mkdir chmod chown ln tee vim vi nano`) which answer `Read-only file system`. `open` navigates to the URL of the node; an unknown path goes to the real 404 URL with the typed path; `curl` is simulated.

## UI
`<joo-terminal>` (dock view module, 1,388 B gzip) only toggles the panel; the first open loads the complete terminal bundle (8,991 B gzip; 9,216 B / 9 KiB budget) and the FS JSON once. The full bundle includes the engine, built-in commands and UI. `ui.js` builds the DOM with `createElement`/`textContent`; the output is a keyboard-scrollable `role="log"` with `aria-live="off"`, so large command output does not flood announcements. A separate visually hidden `role="status"` live region politely announces a compact command result and coalesces rapid updates for 200 ms. Each announcement is capped at 240 characters and points to the log when more output is available. The log remains available to screen readers for review. The loading message and the 404 retry result are also polite status messages.

The dock button is keyboard-operable, reports `aria-expanded`, and advertises the optional Backquote shortcut. Opening focuses the command input after loading; Escape or the close button closes the panel and restores focus to the opener (or the dock button if that opener no longer exists). The command input handles Tab completion only while there is something to complete; Tab on an empty input or on text with no completion, and Shift+Tab, move focus normally, so focus can leave the panel and there is no keyboard trap. The input also handles history arrows, Ctrl+L and Ctrl+C. The UI applies `navigate` effects only to same-origin http(s) URLs, applies theme effects through the `joo:theme` event, and follows the page's matching `hreflang` alternate for language effects. The dock is a right sidebar from 901 px and a bottom sheet below; it is hidden on 404 pages unless `terminal.hide_on_404` is off. The terminal UI uses immediate scrolling and no opening animation; reduced-motion styles keep scrolling immediate and suppress transitions and animations. Terminal and 404 text, focus indicators and controls use high-contrast colors. Themes add commands through `joo/terminal/commands` (same-origin module URLs exporting an array of commands).

## 404 view
Block `joo/not-found`: real 404 page (status and robots from the SEO module) with a transcript, keyboard-accessible search form and server-side suggestions; the path is echoed escaped. `<joo-404>` lets the visitor check another path against the embedded post index without a network request and reports the result in a polite status region. Its ordinary page links and forms stay in the browser's normal tab order; there is no focus trap.
