# Compatibility module

`Compat\Detector` finds plugins by constants, already loaded classes/functions (never autoloading) and the active plugin list, using the table in `Compat\Signatures` (30 plugins, tier 1/2/3). `active()`, `version()`, `provides($capability)`; results are cached per request and the probe is injectable for tests.

## Adapters (`AdapterInterface`)
`AdapterRegistry` boots every adapter whose plugin is active; a failing adapter is logged and isolated. Add or replace adapters with `joo/compat/adapters`.

| Adapter | Behaviour |
|---|---|
| Yoast, Rank Math, SEOPress, AIOSEO | core SEO yields; primary category feeds breadcrumbs (`joo/seo/primary_category`); plugin noindex posts leave the core sitemap (`joo/seo/noindex_post_ids`; AIOSEO keeps its flags in its own table, so this is not automatic there) |
| LiteSpeed, WP Rocket, W3TC, Autoptimize | our script handles/tags are excluded from minify/defer/delay; lazy loading and critical CSS yield when the plugin provides them (`joo/lazy/provider`, `joo/perf/skip_critical_css`); caches are purged when settings or `joo_cache_version` change |
| Smush, EWWW, ShortPixel | lazy-load detection (ShortPixel cannot be detected reliably) |
| Contact Form 7 | assets only on pages with a form (`joo/compat/forms_conditional`) |
| Jetpack | core Open Graph wins while core prints SEO (`seo.yield_jetpack`) |
| WooCommerce (tier 3) | theme support, cart/checkout/account are noindex, never lazy-fragmented, excluded from speculation rules |
| Page builders (tier 3) | `PageBuilder::isBuilderPage()`; content filters must skip these pages |
| Site Kit, TablePress, ACF, Akismet, Wordfence, WPForms, Fluent Forms, Classic Editor | capability flags and notes only |

Known limitation: WordPress script modules cannot carry `data-no-defer` attributes, so exclusion relies on each plugin's documented filters (see the table above).

## Multilingual (`Compat\Multilingual`)
One interface for languages, translations and home URLs with Polylang, WPML, TranslatePress and the built-in tagging (`_joo_lang`, `_joo_translation_of`, manifest `i18n.languages`). `Resolver` picks the first active plugin, else the built-in one. When a plugin is in charge it supplies hreflang alternates through `joo/seo/alternates`.

## Admin and docs
Settings > Compatibility lists detected plugins with tier, adapter state and notes (`joo/compat/report`). `docs/compatibility.md` is generated by `make docs` from `tests/matrix/plugins.json` and the matrix reports; CI fails when it is stale.
