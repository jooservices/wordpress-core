## Title

**JOOservices — WordPress Theme**

The repository slugs remain `jooservices` and `jooservices-resume`.

## Short description

A fast, accessible block theme for editorial sites, with flexible templates,
local fonts, dark mode, and optional company/profile content from JOOservices
Resume.

## Long description

Build an editorial site with JOOservices, a WordPress block theme with full
site editing, responsive templates, and reusable patterns. Customize colors,
typography, layouts, and navigation in the Site Editor. Local font files,
translation support, and performance-minded defaults are included.

JOOservices works without JOOservices Resume. Install the companion plugin
only if you want its company history, author profile, topic, and featured-post
fields. The theme does not require WooCommerce in version 1.0.

The item includes English documentation and a Vietnamese translation. Check
the live demo and the [browser compatibility matrix](../../themes/jooservices/docs/browser-compatibility.md)
for supported versions and completed validation before purchase.
