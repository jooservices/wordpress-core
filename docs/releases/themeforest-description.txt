JOOservices | Technical Blog and Resume WordPress Theme

JOOservices is a dark-first block theme for technical blogs and personal resume sites. It includes a left profile rail, featured posts, archive and article templates, dark and light styles, a read-only terminal dock, and the JOOservices Resume companion plugin for company history and profile data.

INCLUDED
- Installable JOOservices WordPress theme
- JOOservices Resume companion plugin
- English buyer documentation and demo content
- Self-hosted IBM Plex Sans and JetBrains Mono fonts, licensed under OFL 1.1
- Dark and light style variations

REQUIREMENTS
- WordPress 6.6 or newer
- PHP 8.1 or newer
- Tested through WordPress 7.1

COMPATIBILITY
WordPress 6.6+ and PHP 8.1+ are the product minimums. The browser targets are Chrome and Edge current and previous versions, Firefox ESR and current, Safari 16.4+, iOS Safari 16.4+, and Android Chrome current stable. WooCommerce is not required; product, cart, and checkout templates are unstyled. The complete matrix in the buyer documentation lists tested versions and marks unsupported or unvalidated cells.

SUPPORT
Support covers installation and use of the shipped theme and JOOservices Resume plugin, plus reproducible defects on versions marked supported in the compatibility matrix. Requests should include product, WordPress, PHP, database, plugin, theme, browser and operating-system versions, affected URL, and reproduction steps. Support entitlement and any response commitment follow the selected ThemeForest item support terms. No separate response-time SLA is promised.

INSTALLATION AND UPDATES
Install the theme zip in Appearance > Themes. Install and activate the separate JOOservices Resume zip in Plugins. ThemeForest and the Envato Market plugin handle marketplace update delivery. The theme makes no purchase-code or licence-server request and remains functional if marketplace update entitlement expires.
