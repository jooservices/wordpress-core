# Product changelog

## JOOservices theme 0.1.0

2026-10-15. First release candidate: dark and light schemes, left rail, featured slider, post list, resume views, terminal dock, English and Vietnamese interface, and local fonts.

## JOOservices Resume 0.1.0

2026-10-15. First release candidate: company history, profile fields, topic metadata, featured-post controls, and read-only REST data routes.
- Added company location, employment type, roles within a period, achievements, technologies and owner-defined custom fields, with per-field public switches for private compensation and equity.
- Added company editor repeaters, list filters and bulk pin/hide/show actions, plus the Settings custom-field builder.
- Added JSON, JSON Resume and CSV import/export with dry-run support.
- Added the `[joo_resume]` shortcode, `joo/resume` block, REST endpoints `/wp-json/jooservices-resume/v1/resume` and `/resume/json-resume`, and `worksFor` structured data.
