# Five-minute walkthrough: script and storyboard

- **Audience:** a WordPress site owner preparing a technical blog and resume.
- **Recording:** owner records after the licence-clean buyer demo package is available. Use a clean site, hide browser credentials, and capture the current release version.

| Time | Screen and action | Narration |
|---|---|---|
| 0:00–0:25 | Show the homepage at desktop width; point out the rail, featured slider, article list, and header controls. | “JOOservices gives a technical blog a profile rail, featured writing, and a focused reading layout.” |
| 0:25–0:55 | Toggle dark and light styles; resize to a phone viewport. | “Readers can choose a colour scheme, and the layout adapts to narrow screens.” |
| 0:55–1:35 | Open a post with code, table of contents, featured image, and related posts. Use Copy on a code block. | “Posts include reading navigation, code examples, and related content.” |
| 1:35–2:20 | Open **Users → Profile**, show title, biography, avatar, and social fields; then open **Companies**. | “The companion JOOservices Resume plugin supplies the profile and company history shown across the site.” |
| 2:20–3:00 | Open the About page and show the company timeline. | “Enter company records once and reuse them in the resume view.” |
| 3:00–3:35 | Open **Appearance → Editor** and switch between styles; show the Navigation editor. | “Use the WordPress Site Editor to adjust styles, navigation, templates, and footer content.” |
| 3:35–4:10 | Open **Appearance → JOOservices** and briefly show SEO and performance groups. | “The theme includes practical SEO and performance controls. Use one SEO provider at a time.” |
| 4:10–4:35 | Use site search, language switcher, and the read-only terminal. | “Search, language support, and the terminal dock are available from the theme interface.” |
| 4:35–5:00 | End on the ThemeForest help page and version number. | “Install the theme and Resume plugin separately, follow the buyer guide, and check the guide version when updating.” |

Do not claim a one-click demo import, plugin test result, language translation, or performance score that is not present in the current release evidence. Add captions and a transcript before publishing.
