# Changelog

All notable changes to the core are listed here. The version lives in `composer.json`; `tools/check-version.php` keeps it equal to `JOO_CORE_VERSION` in `core.php` and to the newest heading below.

## 0.1.0 - 2026-10-15

First release: kernel, settings and admin, assets and runtime, performance, lazy loading, SEO (head, structured data, sitemaps, HTTP semantics), compatibility layer, content provider and REST routes, block library (content and sidebar blocks), i18n (EN/VI), terminal, developer kit.

### Upgrade notes

- This is the first release: there is nothing to migrate from an earlier version.
- The core version is `0.1.0` in `composer.json` and `JOO_CORE_VERSION` in `core.php`; run `php tools/check-version.php` to confirm the three places agree.
